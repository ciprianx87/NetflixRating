# NetflixRating

Browse every movie available on Netflix in a given country, using TMDB watch-provider data (powered by JustWatch).

## Setup
1. Get a free API key at https://www.themoviedb.org/settings/api (v3 key or v4 read access token both work).
2. `cp config.example.json config.json` and paste the key.
3. `npm start` and open http://localhost:3000

`config.json` is git-ignored.
